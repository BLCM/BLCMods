TPSRelaunched

Bringing it back to 2020 with a non Command Extensioned, fully multiplayer-able Borderlands overhaul... now for the Pre-Sequel!

This mod serves to rebalance the game in many ways so it feels fundamentally familiar, but buildcrafting is clearer and more deterministic. Many of the unique items shared with BL2 have been modified and/or replaced, to offer a bit of freshness, and almost every type of item- unique or otherwise- has been altered in some way to better serve a purpose or stack up to competition.

Difficulty-wise, I would consider it slightly harder than vanilla TPS at base, but you have more potent options for builds such as pure Melee and Status Effects, so previously unviable or niche builds perform far better, even if generic gun builds do a tiny bit worse against the new scaling.

I'll, uh, add more details here and on other platforms once I figure out how to upload the mod in the first place. Stay tuned!
